# gaContExt-managed MCP controls

Files in this directory are copied literally from one versioned common component.
`component.json` records its revision and exact file hashes. Changes belong in the
canonical upstream component or the provider's extension points. A local change
to managed files is reported as a conflict before an update can replace them.

Provider-owned configuration and code live under `mcp/` by default:

- `provider.json`: identity, binding, worker references, capabilities, domain paths
  and named dependency links.
- `Makefile`: the provider's build/check/smoke/stdio recipes.
- Domain modules, Dockerfiles, resources and prompts: maintained by the provider.

Existing domain paths can be mapped explicitly in `provider.json`. The root
Makefile and `mcp/` seeds are copied/parameterised once when absent; later edits
belong to the provider. Registration and W1 companion documents retain their own
schemas and are not generated by this component updater.

The common runtime/client/worker SDK is installed from the same versioned package
dependency. Its code comes from that package; providers extend it with domain
adapters. These copied controls do not certify SDK adoption, prepare images,
execute dependency links or start an agent. Checking/planning is read-only.
