## Native boundary

`UNALTRAWEB_SHARED_JOB_CONTEXT` selects one private operator file at startup. It
binds the original workspace, common service root, explicit Docker endpoint/ID,
task/owner/job/registry IDs, prepared SDK PDF image and host worker UID/GID.
The caller cannot substitute those through a native storage request. The common
service remains the admission authority, including its independent image, user,
mount, resource and lease checks across container namespaces.

`job_storage(request)` and `mcp job-storage --request-json ...` delegate to
`Client.job_storage`. Status does not prepare/reconcile Docker resources and
remains observable after the Web backend is drained. Seal/quiesce keep the exact
manager-side revision/epoch CAS and busy-quiesce response; the client does not
emulate that transaction. Missing configuration returns an explicit unavailable
result without initializing another service or registry.

With an explicit shared context, `manual_practice_pdf_build` stages only the
selected original config/Markdown/images through the common input-file API.
The worker persists its request before rendering, verifies the domain fingerprint,
and retains original factory controls, effective sources, useful logs and PDF.
Regenerable copies, Pandoc/TeX files and previews use **`scratch/tmp/`**. The PDF
toolchain mounts only the issued volumes and RO grant; not the consumer/factory
checkout or Docker socket. A retry returns the existing native seal and keeps the
same task/provider slot. Completion does not close another client's task interest.

The adapter returns a sealed product, not a false durable consumer path. The
operator closes task interests and uses the registered common receiver. The
whole protected snapshot includes originals outside exports. Web independently
verifies the delivered PDF/native bundle and original hashes after producer
retirement and relocation; that check is not teaching approval. The common
retention witness remains structural and keeps `native_integration_verified:false`.

Limits remain the common 512 MiB/file, 2 GiB/snapshot and 10,000 entries, with the
existing Web PDF source/image budgets still stricter. No real large GIS closure
is certified by the small synthetic acceptance.

### Affected owner behavior

Web retains its same-name provider/factory registration. The actual installed
controller can read the issued binding and new `.docker.json` sidecar through its
read-only service mount. `create_args` consumes the manager-owned ownership;
worker admission records factory `unaltraweb` and the canonical original-consumer
project hash. Only the original W1 binding is mounted into the worker.

The private operator context may select `worker_timeout_seconds`, strictly an
integer from 1 to 900 with default 900. Native requests cannot override it. The
SDK enforces that deadline; Web bounds Docker waiting and delegates cancellation
on uncertain observation. Failure responses identify the exact container, lease,
deadline policy and protected recovery path without claiming a successful PDF.

Forced termination motivated two owner fixes:

- The renderer writes its entered command and subprocess output directly to
  `recovery/<lease>/render.log`, with the per-attempt request retained beforehand.
  Preserving diagnostics does not depend on a Python exception handler running.
- Prepared controls live under a per-lease path because effective resource paths
  contain the attempt's scratch root. A same-job retry preserves previous controls
  instead of colliding with or overwriting them.
